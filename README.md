# wastewater-bod-soft-sensor
A neural network-based soft sensor that estimates effluent BOD5 (Biochemical Oxygen Demand) in a wastewater treatment plant from fast, real-time process variables — eliminating the need for a 5-day lab test. Built with Python, scikit-learn, and TensorFlow/Keras; includes ANN, Linear Regression and validated via 5-fold cross-validation.
